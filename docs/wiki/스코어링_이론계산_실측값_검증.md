## 1. 점수 산정 수학 공식 및 콤보 가산 모델

### 1.1. 기본 면도 점수 및 콤보 스트릭 공식
수염 $N$개를 연속해서 깎을 때의 기본 획득 점수($S_{\text{base}}$)는 콤보 스트릭($k$)이 $10$까지 점진적으로 증가한 뒤 상한(Cap)에 도달합니다:

$$S_{\text{base}} = \sum_{k=1}^{N} \Delta S(k), \quad \text{where } \Delta S(k) = 10 \times \min(k, 10)$$

- $k=1$: $+10$점
- $k=2$: $+20$점 (누적 $30$점)
- $k=3$: $+30$점 (누적 $60$점)
- $k=10$: $+100$점 (누적 $550$점)
- $k \ge 10$: 매 깎음마다 $+100$점씩 고정 가산.

### 1.2. 시간 보너스 (Time Bonus)
$$S_{\text{time}} = T_{\text{left}} \times 20 \quad (T_{\text{left}} \ge 0)$$

### 1.3. 올클리어 보너스 (All-Clear Bonus)
$$S_{\text{allclear}} = \begin{cases} 1,000 & (\text{remainingHairs} = 0) \\ 0 & (\text{remainingHairs} > 0) \end{cases}$$

### 1.4. 최종 점수 (Total Score)
$$S_{\text{total}} = S_{\text{base}} + S_{\text{time}} + S_{\text{allclear}}$$

## 3. 1,000회 무작위 브레젠험 Fuzzing 기하 불변성 증명

[`tests/domain/grid-geometry-fuzzing.test.js`](file:///d:/Code305/shaving_him/tests/domain/grid-geometry-fuzzing.test.js)에서 $-100 \sim 100$ 범위의 무작위 난수 좌표를 주입하여 1,000회의 선분 생성 불변성을 증명하였습니다.

```javascript
test('Fuzzing - rasterizeLine mathematical invariant verification (1000 random line vectors)', () => {
    // 1,000개 무작위 선분 벡터 검증
    for (let i = 0; i < 1000; i++) {
        const points = rasterizeLine(r0, c0, r1, c1);

        // 불변식 1: 배열이 비어있지 않음
        assert.ok(points.length > 0);

        // 불변식 2: 시작점과 끝점의 완전 일치
        assert.equal(points[0].r, r0);
        assert.equal(points[0].c, c0);
        assert.equal(points[points.length - 1].r, r1);
        assert.equal(points[points.length - 1].c, c1);

        // 불변식 3: 체비쇼프 거리 기반 점의 개수 일치
        const expectedLength = Math.max(Math.abs(r1 - r0), Math.abs(c1 - c0)) + 1;
        assert.equal(points.length, expectedLength);

        // 불변식 4: 8-방향 인접성 연속성 유지 (구멍 없음)
        for (let j = 0; j < points.length - 1; j++) {
            const dr = Math.abs(points[j + 1].r - points[j].r);
            const dc = Math.abs(points[j + 1].c - points[j].c);
            assert.equal(Math.max(dr, dc), 1);
        }
    }
});
```
- **검증 결과**: **1,000회 시도 중 1,000회 통과 (결함률 0.00%)**.

## 4. 500회 뷰포트 스케일링 좌표 변환 퍼징 검증

- **테스트 환경**: 임의의 마우스 클릭 좌표($-500 \sim 2500$px), 캔버스 크기($100 \sim 1920$px), 뷰포트 오프셋($0 \sim 500$px) 500회 무작위 대입.
- **불변식 보증**:
  1. `result.row`와 `result.col`은 절대 `NaN`이나 무한대(`Infinity`)를 반환하지 않고 유효 정수 반환.
  2. 바운딩 박스 내부 좌표는 항상 `[0, cols - 1]`, `[0, rows - 1]` 범위 내로 안전하게 클램핑/매핑.
  3. 바운딩 박스 외부 좌표는 정확히 `row: -1, col: -1` 에러 코드를 반환하여 안전 차단.
- **검증 결과**: **500회 시도 중 500회 통과 (오차율 0.00%)**.
