## 1. 계층별 소스코드 구조 개요

본 프로젝트는 유지보수성과 테스트 용이성을 확보하기 위해 **순수 도메인 ➔ 추상 포트 ➔ 애플리케이션 ➔ 어댑터 ➔ UI 인터페이스** 5개 계층으로 소스코드를 구조화하여 관리하고 있습니다.

## 2. Domain Core Layer (`src/domain/`)

DOM이나 캔버스 API에 대한 의존성이 0%인 순수 비즈니스 로직 계층입니다.

### 2.1. [`src/domain/hair-grid.js`](file:///d:/Code305/shaving_him/src/domain/hair-grid.js)
- **책임**: 1D `Uint8Array` 비트맵 버퍼를 사용하여 수염의 존재 유무를 관리하고, 면도 시 O(1) 비트 반전 및 Dirty Cell 목록을 반환.
- **주요 API**:
  - `constructor(geometryOrCols, rowsOrHairPositions, hairPositions)`: 그리드 기하 또는 명시적 크기로 초기화.
  - `initHairs(hairPositions: Array<{r: number, c: number}>): void`: 수염 위치 배열을 1D 배열에 1로 마킹.
  - `has(r: number, c: number): boolean`: $(r, c)$ 위치에 수염이 존재하는지 O(1) 조회.
  - `shave(r: number, c: number, radius: number): { count: number, dirtyCells: Array<{r: number, c: number}> }`: 반경 내 수염을 0으로 지우고 제거된 개수와 변경 셀 목록 반환 (0B Memory Allocation).
  - `getRemainingCount(): number`: 남은 수염 개수 반환.
  - `getClearedPercentage(): number`: 클리어율(0 ~ 100%) 계산.
  - `toReadOnlyView(): { has(r, c): boolean }`: UI가 내부 상태를 변개할 수 없도록 `has()`만 노출하는 불변 뷰 객체 반환.

### 2.2. [`src/domain/shave-session.js`](file:///d:/Code305/shaving_him/src/domain/shave-session.js)
- **책임**: 게임 세션 수명주기, 타이머 카운트다운, 상태 머신 통제.
- **주요 상수 및 API**:
  - `SessionStatus`: `{ INIT, RUNNING, PAUSED, WON, TIMEOUT }` 열거형.
  - `initStage(stageData: StageDataDTO): void`: 스테이지 데이터로 세션 및 수염 그리드 리셋.
  - `start() / pause() / resume()`: 세션 상태 전환.
  - `tick(): boolean`: 1초 카운트다운 감소 및 타임아웃 판정.
  - `shave(r, c, radius)`: 면도 커맨드 수행 및 올클리어 시 `WON` 상태 전환.
  - `getSnapshot(): SessionSnapshotDTO`: 불변 세션 스냅샷 DTO 생성.

### 2.3. [`src/domain/session-timer.js`](file:///d:/Code305/shaving_him/src/domain/session-timer.js)
- **책임**: 순수 1초 클록 타이머 서비스. `setInterval` 스케줄링, `unref`, 실행 상태(`isRunning`) 캡슐화.
- **주요 API**:
  - `start(onTick: Function): void`: 타이머 시작 및 주기적 틱 콜백 호출.
  - `stop(): void`: 타이머 중지 및 자원 정리.
  - `isRunning: boolean`: 현재 타이머 실행 여부 조회.

### 2.4. [`src/domain/score-calculator.js`](file:///d:/Code305/shaving_him/src/domain/score-calculator.js)
- **책임**: 연속 콤보 스트릭 계산 및 주입된 전략(`IScoringStrategy`)을 통한 점수 산출 (OCP).
- **주요 클래스 및 API**:
  - `DefaultScoringStrategy`: 기본 배율/보너스 전략 구현체.
  - `ScoreCalculator(strategy)`: 전략 패턴 기반 점수 계산기.
  - `addShave(count: number): number`: 수염 깎임 시 스트릭 증가 및 전략 배율 가산.
  - `calculateFinalScore(timeLeft, remainingHairs)`: `{ baseScore, timeBonus, allClearBonus, totalScore }` 산출.
  - `reset(): void`: 점수 및 스트릭 초기화.

### 2.4. [`src/domain/grid-geometry.js`](file:///d:/Code305/shaving_him/src/domain/grid-geometry.js)
- **책임**: 캔버스 크기와 그리드 행/열 크기를 캡슐화한 불변 값 객체(Value Object).
- **주요 API**:
  - `static default()`: 280열, 219행, 셀 6x6 픽셀 규격 반환.
  - `static fromStageData(stageData)`: 스테이지 DTO 기반 팩토리.
  - `clientToGrid(clientX, clientY, clientRect): { row: number, col: number }`: High-DPI 정규화 좌표 변환 ($[-1, -1]$ 에러 방어).
  - `contains(row, col): boolean`: 유효 그리드 범위 검사.

### 2.5. [`src/domain/line-rasterizer.js`](file:///d:/Code305/shaving_him/src/domain/line-rasterizer.js)
- **책임**: 8-연결 브레젠험(Bresenham) 알고리즘 기반 선분 연속 래스터라이징.
- **주요 API**:
  - `rasterizeLine(r0, c0, r1, c1, callback): Array<{r: number, c: number}>`: 연속된 모든 그리드 좌표를 누락 없이 생성.

### 2.6. [`src/domain/schema-validator.js`](file:///d:/Code305/shaving_him/src/domain/schema-validator.js)
- **책임**: 런타임 DTO 스키마 무결성 검증 (Fail-Fast).
- **주요 API**:
  - `validateStageData(stageData): void`: `rows`, `cols`, `totalHairCount`, `hairPositions`, `textGrid`, `colorGrid` 타입 검증.
  - `validateSnapshot(snapshot): void`: `SessionSnapshotDTO` 런타임 무결성 검증.

### 2.7. [`src/domain/game-policy.js`](file:///d:/Code305/shaving_him/src/domain/game-policy.js)
- **책임**: 게임 룰 비즈니스 정책 판정.
- **주요 API**:
  - `isVictory(snapshot): boolean`: `remainingHairs === 0` 판정.
  - `getClearedPercentage(snapshot): number`: 클리어율 계산.

## 7. TypeScript DTO 스키마 명세 (`src/types/index.d.ts`)

```typescript
export interface HairPosition {
    r: number;
    c: number;
}

export type RGBTuple = [number, number, number];
export type RGBATuple = [number, number, number, number];
export type ColorCell = RGBTuple | RGBATuple;

export interface StageDataDTO {
    rows: number;
    cols: number;
    totalHairCount?: number;
    hairPositions: HairPosition[];
    textGrid?: string[];
    colorGrid?: ColorCell[][] | null;
}

export interface FinalScoreResult {
    baseScore: number;
    timeBonus: number;
    allClearBonus: number;
    totalScore: number;
}

export interface SessionSnapshotDTO {
    status: 'INIT' | 'RUNNING' | 'PAUSED' | 'WON' | 'TIMEOUT';
    timeLeft: number;
    maxTime: number;
    score: number;
    comboCount: number;
    finalResult: FinalScoreResult;
    remainingHairs: number;
    totalHairs: number;
    percentageCleared: number;
}

export interface IScoringStrategy {
    calculateMultiplier(streak: number): number;
    calculateTimeBonus(timeLeft: number): number;
    calculateAllClearBonus(remainingHairs: number): number;
}
```
